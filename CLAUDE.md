# Personal Website — Kelvin Fang

Portfolio site. Single-page home (hero → projects → skills → contact), a resume PDF
page, project detail pages, and one API route backing the contact form.

## Stack

- **Next.js 16.3.3** — App Router only, no `pages/` directory
- **React 19.2.8**
- **Tailwind CSS v4, CSS-first** — there is no `tailwind.config.*`. Theme tokens live in
  the `@theme inline` block in `app/globals.css`. Do not create a Tailwind config file.
- **TypeScript**, `strict: true`, path alias `@/* → ./*`
- `react-icons` for skill/tech icons

## Layout

```
app/                     routes
  layout.tsx             root layout: fonts, metadata, <Nav/>
  page.tsx               home page ("use client")
  globals.css            @import "tailwindcss" + @theme inline + keyframes
  Resume/page.tsx        /Resume — PDF viewer
  projects/[slug]/       project detail pages
  api/contact/route.ts   contact form endpoint (the only route handler)
components/              flat, no subdirectories
data/                    typed content: projects.ts, skills.tsx, Icons.tsx
public/                  resume PDF + photos
```

No `src/`, no `lib/`, no `middleware.ts`, no test runner, no CI.

## Conventions

- **Server components by default.** `"use client"` is currently on `app/page.tsx` and on
  `Carousel`, `ContactForm`, `Elipitcal`, `PhotoCollage`, `Reveal`, `Type`.
- **Content lives in `data/` as exported typed arrays**, not inline in components.
  New content belongs in a `data/*` file with an exported type.
- Fonts via `next/font/google`, exposed as CSS variables on `<html>` in `layout.tsx`.
- Colors are currently hardcoded hex literals inline (`#0B0D13`, `#7DA99E`, `#E8EAF0`,
  `#a0a8bb`, `#5a6278`). Moving these into `@theme` tokens is planned — see `plan.md`.

## Next 16 specifics (differ from older training data)

- `params` and `searchParams` are **Promises** and must be awaited.
- Global typed-route helpers `LayoutProps<"/">` and `PageProps<"/route/[param]">` are
  available without importing them. Already used in `app/layout.tsx` and
  `app/projects/[slug]/page.tsx`.
- Read `node_modules/next/dist/docs/` before writing framework code — this version has
  breaking changes from what may be in training data.

## Integrations

`app/api/contact/route.ts` — Upstash sliding-window rate limit (10/min, keyed on the
first `x-forwarded-for` IP) gating a Resend email send.

Env vars, all in `.env.local` (gitignored, no `.env.example` yet):
`RESEND_API_KEY`

The sender is Resend's `onboarding@resend.dev` sandbox domain, which only delivers to
the Resend account owner. A verified domain is needed for real delivery.
